图片拼接工具使用教程：从选画布到导出高清成品

下面按真实操作顺序讲解拼图工坊的完整用法：先定画布比例，再导入图片、套用排列方式，然后自由拖拽、加字、调图层，最后选择倍率导出。跟着走一遍，任何人几分钟内都能拼出可交付的成品。

完整操作流程（七步）

工具界面分为左侧设置面板、中间画布和右侧属性面板。左侧负责画布与全局参数，中间是你真正操作的地方，右侧显示当前选中图层的细节。下面的七步是一份完整的最小闭环，完成后你就掌握了工具的全部核心操作。

1

设置画布尺寸与背景

在左侧「画布尺寸」中点击一个比例快捷按钮（1920×1080 的 16:9、1080×1920 的 9:16、1440×1080 的 4:3、1080×1440 的 3:4、1200×1200 的 1:1 等），或直接填写宽高像素数。再用取色器设定画布背景色，深色背景配浅色图片通常更协调。

2

添加本地图片

点击「添加图片」在文件对话框里一次选中多张图片；更快的做法是把文件直接拖到画布上松手。无论哪种方式，图片都从本地读取并渲染在浏览器里，不会上传，也不会被写入任何存储。

3

选择排列方式并应用

在「排列方式」中选择横向、纵向、网格或自由，点击「应用到图片」。工具会按画布尺寸等比缩放并均匀排布，自动布局只做起点，之后每张图仍可单独调整。

4

拖拽微调位置与大小

按住图片拖动改变位置，拖边角控制点等比缩放，拖顶部圆点旋转。图片多时按住 Shift 或在图层列表中勾选可多选，批量移动和统一缩放；视图太大时按住空格拖拽平移画布。

5

插入并设置文字

点击「添加文字」创建一个文本图层，拖到需要的位置，在右侧设置文字内容、字号、颜色、字体、字重、对齐方式和行高。文字同样是可拖拽的图层，能被图片压住，也能压在图片上方。

6

调整图层顺序

在图层列表中拖动条目即可改变上下顺序。遮挡关系不对时，通常把文字提到最上层就能解决；不再需要的图层选中后删除，误删可以撤销。

7

导出高清成品

点击「导出图片」，选择 PNG、JPEG 或 WebP 格式，以及 1×、2×、3× 倍率，确认后浏览器直接生成文件并触发下载。成品不带水印，导出后原画布仍然保留，可以继续修改。

各功能详解

画布尺寸：先决定成品要用在哪里

画布尺寸决定了导出图片的像素总量，比例选错往往意味着后面全部要返工。横屏展示、演示文稿与视频封面用 16:9；手机竖屏、短视频与 Story 用 9:16；电商主图与头像用 1:1；需要自然比例的照片组用 3:2 或 2:3；图文并茂的长内容用 4:3 或 3:4。

快捷按钮只负责填数字，如果你要的是更特殊的比例，直接在宽度和高度输入框里键入即可。需要精细控制时，建议先按成品尺寸的百分之百建画布，最后靠导出倍率提升分辨率，而不是一开始就建一张很大的画布。

添加图片：文件选择与拖拽两种方式

点击「添加图片」会打开系统文件对话框，支持按住 Ctrl 或 Shift 多选，一次导入十几张没有问题。拖拽上传同样有效：把文件拖到画布区域，界面出现高亮提示时松手即可，批量拖入整个文件夹里的图片时也可以直接拖入。

格式方面，凡是浏览器能解码的图片都可以：JPG / JPEG、PNG、GIF、WebP、AVIF、BMP 等常见格式都能正常读取。如果某张图显示异常，通常是文件本身损坏或格式过于特殊，换一张同格式的图片即可确认。

排列方式：横向、纵向、网格与自由

横向排列会把图片沿宽度方向依次铺开，得到一条宽长图；纵向排列沿高度方向铺开，得到常见的竖版长图；网格排列会自动计算行列数，把图片排成规整的方阵；自由模式则不自动排布，适合你心里已经有明确构图的复杂版面。

需要提醒的是，网格模式下的行列由工具根据画布比例和图片数量自动推算，如果你想要「三行两列」这种固定结构，最稳妥的做法仍然是先切到自由模式，再逐张拖到位。自动排布始终保持原始宽高比，不会把图片硬拉变形。

拖拽、缩放与旋转

鼠标左键按住图片即可拖动；选中图片后，四个边角会出现缩放控制点，拖动它们可以等比缩放，保持图片不变形；顶部有一个圆形控制点，拖动即可旋转角度。缩放时按住 Shift 通常可保持等比，具体以画布上的提示为准。

滚轮可以缩放画布视图，方便在细节与整体之间切换；按住空格键再拖拽鼠标，则是平移画布的手法。当画布在屏幕上显示得太小时，用这两个操作比反复调整图片本身更省事。

文字：内容与样式的完整设置

点击「添加文字」会在画布中央生成一个文本框并自动进入编辑状态。右侧属性面板可以设置文字内容、字号、颜色、字体、字重（常规、加粗等）、对齐方式（左对齐、居中、右对齐）以及行高。行高决定多行文字之间的疏密，做标题时调大一点能让版面更透气。

文字图层的操作方式和图片完全一致：拖动改位置、拖角缩放、拖顶旋转、调整图层顺序改遮挡。排版时把文字放在图片上方、序号或说明放在图片下方，是最不容易出错的层级关系。

图层顺序与工程保存

右侧图层列表按从上到下的顺序显示堆叠关系，列表越靠上的元素在画面中越靠前。把文字从列表中间拖到顶部，它就会盖住所有图片。除了删除，还可以在列表中复制图层，方便放置同一个图章、标签或水印到多个位置。

如果版面比较复杂，建议中途就保存一次。点击「保存工程」会下载一个 JSON 文件，里面记录了画布尺寸、背景色、每个图层的类型、位置、缩放、旋转与文字样式。之后点击「打开工程」载入这个 JSON，即可回到完全相同的编辑状态继续调整（图片素材需要重新从本地选择）。

导出：格式与倍率的组合

导出面板提供 PNG、JPEG、WebP 三种格式和 1×、2×、3× 三档倍率。PNG 无损压缩、支持透明背景，适合带文字或需要叠加使用的素材；JPEG 体积小、兼容性最好，适合直接发布；WebP 在画质与体积之间平衡得不错，适合网页场景。

倍率是画布尺寸的整数倍。以 1920×1080 的画布为例，1× 输出 1920×1080，2× 输出 3840×2160，3× 输出 5760×3240。倍率越高，文件越大、渲染耗时越长，日常发布用 1× 或 2× 已经足够，需要印刷或在高分辨率屏幕上使用时再选 3×。

四个常见场景的做法

同样的功能在不同场景里有不同的最优路径。下面四个配方覆盖了绝大多数日常拼接需求，可以直接照着做。

拼接成长图

画布设为 1920×1080（16:9）铺横图，1080×1920（9:16）铺竖图；添加图片后选「纵向」排列并点击「应用到图片」，图片会按画布高度依次排下。想在顶部加标题，就先「添加文字」再把图层提到最上层。长图太长时可分段拼好再导出，或直接提高倍率保证清晰度。

制作九宫格

画布选 1200×1200（1:1），添加九张尺寸接近的图片，排列方式选「网格」并应用，工具会自动算出三行三列。若想留出间距，可以在网格基础上切到「自由」逐张微调，或把某几张放大做主图，再用图层顺序把主图放到最上层。

给海报加文字

先按投放位置定好画布比例，再放上底图；点击「添加文字」写下主标题，用字号和颜色与背景形成对比，行高调到 1.2 左右更易读。需要多层信息时，标题、副标题、日期分别建三个文字图层，靠调整图层顺序决定压盖关系，最后统一导出。

拼接证件照与资料图

把证件照与需要展示的文件页放在一起排版时，全部操作都在本地完成，敏感内容不会上传。排版时注意使用 1:1 或 3:4 这类接近证件照原始比例的画布，导出选 PNG 可以避免压缩带来的边缘伪影，文字标注用小字号并对齐到统一基线。

遇到问题怎么排查

下面几类是使用中最常出现的情况，按顺序排查通常两三分钟就能定位。

  • 图片被拉伸变形：不要手动拉宽图框，改用边角控制点等比缩放；自动排列本身不会变形，变形多半来自手动拖拽边而非拖角。
  • 点击「应用到图片」没反应：先确认画布里确实已经有图片，没有图片时自动排布无从执行。
  • 导出文件打不开：检查导出格式与后缀是否一致，JPEG 请使用 .jpg 后缀；另外浏览器可能拦截自动下载，允许本站下载即可。
  • 画面卡顿：图片数量多且倍率又高时渲染压力较大，可以先用 1× 预览排版，确认无误后再用 2× 或 3× 导出。
  • 文字位置被图片盖住：在图层列表中把文字条目向上拖动即可置于顶层。
  • 工程文件打不开：请使用本工具导出的 JSON 格式工程文件，其他软件的工程文件无法互相读取。
